# Algorithm Notes

这里记录我的算法学习过程，主要分享竞赛题目的代码、解题思路和常用模板。

## 内容

- Codeforces 题解与代码
- AtCoder 题解与代码
- 常用算法和数据结构模板
- 解题过程中遇到的问题、优化方法与易错点

## 目录

```text
algorithm-notes/
├── codeforces/    # Codeforces 题目
├── atcoder/       # AtCoder 题目（持续更新）
└── 模板.cpp       # 常用竞赛模板
```

题目通常按照比赛编号或题目编号分类。部分目录可能暂时为空，内容会随着学习持续补充。

## 说明

- 代码以 C++ 为主。
- 题解会尽量记录从朴素思路到优化方案的推导过程，而不只给出最终代码。
- 所有内容主要用于个人复习和算法交流，不保证每份代码都是唯一或最优解法。

如果这些内容对你有帮助，欢迎交流讨论。
